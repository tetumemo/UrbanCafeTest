# Urban Cafe Test

都会風カフェサイト「UrbanCafe」のテスト用リポジトリです。本番側は [UrbanCafe](https://github.com/tetumemo/UrbanCafe) です。

## ページ

Next.js（App Router）で作られています（`app/`）。

- `/` — トップ（`app/page.tsx`）
- `/menu` — メニュー（`app/menu/page.tsx`）
- `/contact` — お問い合わせ（`app/contact/page.tsx`）

## 技術構成

Next.js + React + Tailwind CSS。

## 動かし方

```bash
npm install
npm run dev
```

> テスト用のため、内容は本番と異なる場合があります。
